🧩 Regras da API

Remoção de Autor:
Antes de remover um autor, é necessário deletar todos os livros correspondentes a esse autor.

Remoção de Editora:
Antes de remover uma editora, é necessário deletar todos os livros vinculados a essa editora.

Remoção de Empréstimo:
Antes de remover um empréstimo, é necessário verificar se todos os livros relacionados ao empréstimo foram devidamente devolvidos.
